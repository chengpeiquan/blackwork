# Blackwork

Blackwork is a React UI library inspired by Blackwork tattoos, for blogs, documentation, and other content sites.

The name comes from the original aim: to carry the aesthetic of Blackwork tattoos into a personal website. Ink, linework, and negative space shape the visual foundation, while layouts and controls give content a place to live. Liquid glass is an optional material within that style.

Start by installing the package and importing its styles, then build a page with layouts, theme controls, and form components.
