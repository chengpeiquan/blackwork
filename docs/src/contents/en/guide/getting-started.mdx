# Getting Started

The common path is: install `blackwork`, import one stylesheet, configure the root theme, and render a first `Button`. The remaining guides build on this setup.

Blackwork provides layouts, theme controls, and interactive components for blogs and documentation sites. This site and the blog [chengpeiquan.com](https://chengpeiquan.com/) use the same components and serve as working examples.

Start with installation and styles, then use the Next.js App Router example below to build a page with a theme toggle.

<Callout title="Requirements">Use React 19+ and Tailwind CSS v4.</Callout>

## Create a documentation site

For a new documentation site, use the Blackwork Docs Starter with
[Create Preset](https://preset.js.org). It includes Next.js, Markdown and MDX,
English and Chinese content, theme controls, and static search.

With Node.js, Git, and pnpm installed, run:

```bash
pnpm dlx create-preset init my-docs --from https://raw.githubusercontent.com/chengpeiquan/blackwork/main/presets/docs-starter.json
cd my-docs
pnpm install
pnpm dev
```

Open `http://localhost:3300`. The CLI copies the maintained starter and replaces
workspace dependencies with published npm versions. The
[preset config](https://github.com/chengpeiquan/blackwork/blob/main/presets/docs-starter.json)
is maintained in the Blackwork repository.

Build the static site and its search index, then preview the result:

```bash
pnpm build
pnpm start
```

The output is in `.next-static`, and the preview runs at `http://localhost:4300`.
Search assets are generated during the build; use this preview to check search.
To add Blackwork to an existing React project, follow the installation steps below.

## Installation

```bash
pnpm add blackwork
```

For forms built with `blackwork/form`, also install TanStack Form:

```bash
pnpm add @tanstack/react-form
```

## Import styles

Import Tailwind and Blackwork in the app stylesheet:

```css title="src/app/globals.css"
@import 'tailwindcss';
@import 'blackwork/tailwind.css';
```

To replace the default sans-serif font, set `--blackwork-font-sans`:

```css title="src/app/globals.css"
:root {
  --blackwork-font-sans: 'Your Font', sans-serif;
}
```

For theme variables and global styles without Tailwind scanning Blackwork component classes, use these entries instead:

```css
@import 'blackwork/theme.css';
@import 'blackwork/ui-globals.css';
```

## Set up Next.js

Import the styles in the root layout and use `ThemeProvider` to manage the theme. Place `ThemeScript` in `head` to apply the theme before the content appears, avoiding a flash between light and dark mode. This layout includes a header, main content, footer, and theme toggle.

```tsx title="src/app/layout.tsx"
import { LayoutHeader, ThemeProvider, ThemeToggle } from 'blackwork'
import { LayoutFooter, LayoutMain, ThemeScript } from 'blackwork/rsc'
import './globals.css'

const RootLayout = ({ children }: React.PropsWithChildren) => {
  return (
    <html lang="en" suppressHydrationWarning>
      <head>
        <ThemeScript />
      </head>
      <body className="flex min-h-dvh flex-col">
        <ThemeProvider>
          <LayoutHeader themeToggle={<ThemeToggle />}>My site</LayoutHeader>
          <LayoutMain>{children}</LayoutMain>
          <LayoutFooter>© My site</LayoutFooter>
        </ThemeProvider>
      </body>
    </html>
  )
}

export default RootLayout
```

## First component

```tsx title="src/app/page.tsx"
import { Button } from 'blackwork'

const Page = () => {
  return <Button>Get started</Button>
}

export default Page
```

<Callout title="Server components">
  Button, overlays, and most interactive components come from blackwork.
  Server-renderable layouts and primitives come from blackwork/rsc.
</Callout>

Verify the first page in both themes before adding more components. Then explore [Layouts](/components/layouts), [Theme](/components/theme), and [Widgets](/components/widgets). The [component overview](/components) lists the remaining components and the API differences to check when using shadcn/ui examples.
