# Field

Use `Field` to keep a control, its label, supporting text, and validation message in one accessible layout. It does not store values or submit forms.

## When to use

- Any labeled input, even outside a form library
- Horizontal settings rows
- Showing a description or a validation message next to the control

Use [Form](/components/form) to manage field values, validation, and submission with TanStack Form.

### Validation
