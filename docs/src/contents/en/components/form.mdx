# Form

blackwork/form connects [TanStack Form](https://tanstack.com/form) to Field.

<Callout title="Note">
  It is not a form engine. It only binds TanStack Form to Blackwork fields.
</Callout>

Install the peer first:

```bash
pnpm add @tanstack/react-form
```

## When to use

- A real submit flow with values and validation
- Reuse `TextField`, `TextareaField`, or `CheckboxField`

If you only need a labeled input, use [Field](/components/field).
