# 图标

Blackwork 的通用图标使用 [`lucide-react`](https://lucide.dev)，例如搜索、主题切换和关闭按钮中的图标。

```tsx
import { Moon, Search, Sun } from 'lucide-react'

export const SearchMark = () => {
  return <Search className="size-4" />
}
```

项目中尚未安装 `lucide-react` 时，先添加依赖：

```bash
pnpm add lucide-react
```

<Callout title="品牌图标">
  Lucide 1.x 不包含品牌标志。GitHub、X、知乎、npm 等品牌图标可以使用本地 SVG，
  与使用图标的功能代码放在一起。Blackwork 为 `SocialLink` 内置了部分品牌图标，
  用法见 [小工具](/zh/components/widgets)。
</Callout>

## 常见名称对照

`blackwork/icons` 入口已移除。迁移旧代码时，以下图标需要使用对应的 Lucide 名称：

| 旧名称     | Lucide            |
| ---------- | ----------------- |
| `Close`    | `X`               |
| `Language` | `Languages`       |
| `Toc`      | `TableOfContents` |
| `Loader`   | `Loader2`         |

升级已有项目时，见 [迁移指南](/zh/guide/migration)。
