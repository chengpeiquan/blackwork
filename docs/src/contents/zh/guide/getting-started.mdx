# 快速开始

Blackwork 提供博客和文档站常用的布局、主题和交互组件。本站和博客 [chengpeiquan.com](https://chengpeiquan.com/) 都使用这套组件，可以作为实际页面的参考。

下面从安装和样式配置开始，再以 Next.js App Router 为例搭建一个带主题切换的页面。

<Callout title="环境要求">需要 React 19+ 和 Tailwind CSS v4。</Callout>

## 安装

```bash
pnpm add blackwork
```

使用 `blackwork/form` 构建表单时，还需要安装 TanStack Form：

```bash
pnpm add @tanstack/react-form
```

## 引入样式

在应用样式表里引入 Tailwind 和 Blackwork：

```css title="src/app/globals.css"
@import 'tailwindcss';
@import 'blackwork/tailwind.css';
```

如果要覆盖默认无衬线字体，设置 `--blackwork-font-sans`：

```css title="src/app/globals.css"
:root {
  --blackwork-font-sans: 'Your Font', sans-serif;
}
```

如果只需要主题变量和全局样式，不需要 Tailwind 扫描 Blackwork 组件的类名，可以改用以下入口：

```css
@import 'blackwork/theme.css';
@import 'blackwork/ui-globals.css';
```

## 接入 Next.js

在根布局引入样式，用 `ThemeProvider` 管理主题。`ThemeScript` 放在 `head` 中，让页面在显示内容前应用主题，避免浅色和深色之间的闪烁。下面的布局包含页头、正文、页脚和主题切换按钮。

```tsx title="src/app/layout.tsx"
import { LayoutHeader, ThemeProvider, ThemeToggle } from 'blackwork'
import { LayoutFooter, LayoutMain, ThemeScript } from 'blackwork/rsc'
import './globals.css'

const RootLayout = ({ children }: React.PropsWithChildren) => {
  return (
    <html lang="zh-CN" suppressHydrationWarning>
      <head>
        <ThemeScript />
      </head>
      <body className="flex min-h-dvh flex-col">
        <ThemeProvider>
          <LayoutHeader themeToggle={<ThemeToggle />}>我的网站</LayoutHeader>
          <LayoutMain>{children}</LayoutMain>
          <LayoutFooter>© 我的网站</LayoutFooter>
        </ThemeProvider>
      </body>
    </html>
  )
}

export default RootLayout
```

## 第一个组件

```tsx title="src/app/page.tsx"
import { Button } from 'blackwork'

const Page = () => {
  return <Button>开始使用</Button>
}

export default Page
```

<Callout title="服务端组件">
  Button、浮层和大部分交互组件从 blackwork
  引入。可以在服务端渲染的布局和基础组件从 blackwork/rsc 引入。
</Callout>

页面运行后，可以继续查看 [布局](/zh/components/layouts)、[主题](/zh/components/theme) 和 [小工具](/zh/components/widgets) 的用法。[组件总览](/zh/components) 列出了其他可用组件，也说明了参考 shadcn/ui 示例时需要注意的 API 差异。
