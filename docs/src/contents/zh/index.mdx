# Blackwork

Blackwork 是一套源于 Blackwork 纹身风格的 React UI，适合搭建博客、文档站和其他以内容为主的网站。

名字来自最初的设计意图：让个人网站也能延续 Blackwork 纹身的审美。墨色、线条与留白构成界面的视觉基础，布局与交互组件则负责承载内容。液态玻璃是这套风格下可选的材质表现。

从安装组件包和引入样式开始，再用布局、主题和表单组件搭建页面。
