# 小工具

这些是给内容站用的小工具，不是 shadcn 那套基础组件。

`LanguageToggle` 和 `SocialLinks` 适合放进 [LayoutHeader](/zh/components/layouts)。本站已经挂了 `ScrollToTop`。

## 适用场景

- 页头切换语言
- 搜索框或命令面板入口
- GitHub、X、RSS 等品牌图标
- 和字号阶梯对齐的标题和正文

通用图标仍从 `lucide-react` 引入，见 [图标](/zh/guide/icons)。品牌图标只放在 `SocialLink` 里。

## 说明

- `SocialLink` 只认识 `github`、`x`、`twitter`、`instagram`、`zhihu`、`rss`。
- `ScrollToTop` 是 `position: fixed`。装箱预览时用 `className` 覆盖。
- `SearchInput` 只负责外观，提交或过滤要自己接。
- 本站页头搜索是 `QuickSearchDialog` 的消费者，不是另一套组件。
