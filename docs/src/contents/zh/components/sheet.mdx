# Sheet

## 适用场景

- 移动端导航
- 列表的筛选面板
- 保留部分列表作为参考，查看或编辑某一项

简短的确认操作可以使用居中显示的 [Dialog](/zh/components/dialog)。

## 说明

- 默认 `side` 是 `right`。
- 设置 `closeButtonVisible={false}` 会隐藏内置关闭按钮，此时需要提供其他关闭控件。
- 与 `Dialog` 一样，触发器使用 `asChild` 时，子节点需要是 `<button>` 或 `Button`。
