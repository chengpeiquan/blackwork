# Blackwork 文档起步模板

这个 starter 保持足够轻量，但已经包含了真实项目最常用的
`content.config.ts` 配置方式。

## 这个 starter 在教什么

- `guide/**` 是带手写 sidebar 的 docs 风格 section。
- `reference/**` 是不显示左侧 docs sidebar 的 content 风格 section。
- `src/contents/<locale>/` 下的第一级目录会成为 section key。
- Markdown 和 MDX 页面可以在同一个 starter 里混合使用。

## 建议阅读顺序

1. 先看 [Guide](/zh/guide)，理解 docs 风格 section。
2. 再看 [配置 Sections](/zh/guide/configuring-sections)，直接复制配置。
3. 最后打开 [配置参考](/zh/reference/configuration)，对比 `content`
   布局的效果。
