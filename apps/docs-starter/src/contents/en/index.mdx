# Blackwork Docs Starter

This starter is intentionally small, but it still demonstrates the most common
`content.config.ts` patterns you need in a real docs site.

## What this starter teaches

- `guide/**` is a docs-style section with a manual sidebar.
- `reference/**` is a content-style section without the left docs sidebar.
- The first directory under `src/contents/<locale>/` becomes the section key.
- Regular Markdown and MDX pages can live side by side inside the same starter.

## Suggested path

1. Start with [Guide](/guide) to see the curated learning section.
2. Open [Configuring Sections](/guide/configuring-sections) to copy the config.
3. Visit [Configuration Reference](/reference/configuration) to compare the
   `content` layout.
